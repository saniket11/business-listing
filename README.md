# Business Listing & Rating System

This is a Core PHP + MySQL based Business Listing application where users can:
- Add, edit, and delete businesses
- Submit star ratings for businesses
- View average ratings for each business
- Perform all actions using AJAX without page reload

---

## Features
- Business CRUD (Add / Edit / Delete)
- Star rating system using jQuery Raty
- Average rating calculation
- Bootstrap 5 modals
- AJAX-based form submission
- Soft delete using delete_flag
- Form validation and reset handling

---

## Technologies Used
- Core PHP
- MySQL
- HTML, CSS, JavaScript
- jQuery
- Bootstrap 5
- Font Awesome
- jQuery Raty Plugin

---

## Project Setup

### 1. Requirements
- PHP 7.4 or higher
- MySQL
- Apache (XAMPP / WAMP / LAMP)

---

### 2. Database Setup
1. Create a database in MySQL
2. Import the `business_rating_system.sql` file

---

### 3. Database Configuration
Open the file:

Update database credentials:

$host = "localhost";
$user = "root";
$password = "";
$database = "business_rating_system";

### 4. Run the Project
http://localhost/business-listing/
